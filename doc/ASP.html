Overview

gate_asp.rb

Generates ASP causal rules (in the event/steady style used throughout this conversation) for a logic gate, given:

- its boolean function (as a block: Array[0/1] -> 0/1)
- the number/names of its inputs
- the name of its output
- the R/F propagation delays

The generated rules follow the pattern we built by hand for OR and AND:

event(out, r, T) :- event(in1, r, T-DR), steady(in2, s0, T-DR).
event(out, r, T) :- event(in1, r, T-DR), event(in2, r, T-DR).
... etc, one rule per minimal causal condition found in the truth table.

Method: for every nonempty subset S of inputs simultaneously transitioning (from_val -> to_val) and every 0/1 assignment of the remaining ("steady") inputs, check whether the function actually flips output from from_val to to_val under that scenario. If so, emit the corresponding ASP rule.
